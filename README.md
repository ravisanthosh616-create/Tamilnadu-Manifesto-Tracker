# Tamil Nadu Political Manifesto Tracker | Power BI

## Project Overview

The Tamil Nadu Political Manifesto Tracker is a Power BI dashboard project designed to organize and compare political manifesto commitments with reported government actions across two periods:

- 2016–2021
- 2021–2026

The project aims to make manifesto commitments easier to explore through structured data, visual reporting, and status-based comparisons.

## Objectives

- Organize manifesto commitments into a structured dataset.
- Compare commitments across the two government periods.
- Track reported implementation status.
- Present information through interactive Power BI visuals.
- Support transparent, evidence-based exploration of public commitments.

## Data Quality & Limitations

Manifesto commitments and implementation status should be interpreted using their documented sources and definitions.

A recorded status does not independently prove that a commitment was fulfilled. Data completeness, source reliability, and the criteria used to classify implementation may affect the results.

This project is an analytical and educational dashboard, not an official government assessment.
